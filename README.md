# JavaScript DOM Lab
Colección de ejercicios interactivos para practicar JavaScript en el navegador, con el foco puesto en
* manipulación del DOM;
* manejo de eventos;
* generación dinámica de eventos;
* y validación de formularios.

## Funcionalidades
* Menú desplegable.
* Modo oscuro.
* Mostrar/Ocultar contenido.
* Validación de formulario de contacto.
* Galería de productos con búsqueda en tiempo real.
* Generador dinámico de tarjetas.
* Saludo según la hora del día.
* Calculadora de edad.
* Acordeón de preguntas frecuentes.
* Contador de carácteres en tiempo real.
